## Orden de lectura

1. Leer el documento conceptual para conocer arquitectura de información, navegación, inventario de pantallas y recorridos.
2. Consultar la guía de identidad para elegir logo y superficie de uso.
3. Consultar el sistema visual para paleta, temas, tipografía, componentes y estados.
4. Revisar la edición Word o PDF que reúne el contenido completo y las capturas de referencia.
